# Страйкбольный клуб РТУ МИРЭА

Откройте `dist/airsoft.html` двойным щелчком. Страница содержит React, оформление, фотографии и шрифты. Для просмотра Яндекс Карт и перехода к сообществу ВКонтакте нужен интернет. Для переходов из сайта Центра используйте имя файла `airsoft.html` и прежние якоря, в том числе `#contact` и `#field`.

## Разработка

Проверено с Node.js 24 и npm 11. В папке проекта выполните:

```sh
npm ci
npm run dev
```

Локальный адрес появится в терминале. Для создания готового файла выполните `npm run build`. Исходники страницы лежат в `src`, настройки сборки — в `scripts/build.mjs`. Дата и взнос ближайшей игры, ссылка на объявление и общий прайс находятся в `src/club.js`. Чтобы подключить Метрику после получения ID счётчика, заполните метатег `yandex-metrika-id` в `template.html` и пересоберите сайт.

## Проверка сборки

В Chrome проверены размеры 320 × 568, 390 × 844, 768 × 1024 и 1440 × 900, состояние анонса до и с момента начала игры, стоимость услуг, якорные переходы, контактные ссылки, увеличение схемы, перелистывание фотографий мышью и клавиатурой, частые вопросы и пауза анимации. Мобильные размеры проверены в эмуляции. Реальный звонок и доставка сообщения сотруднику требуют участия клуба.
